# corazoncp-landing

The public-facing marketing and discovery website for **El Corazón como Portal** (Azu Seva Surpreet Kaur).

---

## 🎯 Deliverable Objective

To deliver a high-converting, serene, and responsive mobile-first landing page this week that:
1. Conveys Azu's spiritual presence and core approach.
2. Curates her active offerings (Access Bars®, Body Process, Mentoring, Oidaterapia).
3. Connects prospective clients directly to a conversation via WhatsApp without form friction.

For full product specifications and acceptance criteria: [See Landing Page Brief](./docs/specs/landing-page-brief.md)

---

## 🏗️ Technical Architecture

- **Stack:** Static-first web application (to be implemented on `feat/anne/*` by Anne Droid).
- **Primary Conversion:** Direct WhatsApp links (`https://wa.me/573123907177?text=...`).
- **Deferred:** Appointment scheduling backend and payment gateway.
